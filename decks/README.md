# Meeting decks

Real packs live here, one folder per slug. The 593-slide Figma file is the
**library**. Do not append board or weekly narrative to it.

```
decks/<slug>/
  STATE.md       fileKey, audience, storyline map, export dest
  BRIEF.md       from cakewalk-brief
  STORYLINE.md   from cakewalk-storyline
  CAST.md        from cakewalk-cast
  JUDGEMENT.md   from cakewalk-critique
```

Schemas: `skill/references/`. The parent `/cakewalk-slides` skill writes these
after each subagent returns.

Operating slides that already live at library positions 577–593 are history;
new work like them starts a folder here and a **new** Figma Slides file.
